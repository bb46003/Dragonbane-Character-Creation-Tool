# Dragonbane Character Creation Tool
<p>Allow users to create characters using the character creation rules defined in the Dragonbane Core Book.</p>
<p>If you also have the Dragonbane Core Module installed, you can use the random tables provided by the module. Alternatively, you can use your own random tables, but their names must match the corresponding elements. For example, a random table for a profession should have "Gear" or its localized equivalent in its name, together with the profession name, such as "Gear - Merchant".</p>
<p>The same naming convention applies to random tables for names, mementos, weaknesses, and other character creation elements.</p>
<p>For attributes, the default Dragonbane method is implemented: roll 4d6, keep the 3 highest results, and sum them. If you prefer to use a different method, you can simply enter your attribute values manually.</p>
<p>An Actor can be created for any user if a GM is logged into the world, or if the user has permission to create new Actors.</p>
